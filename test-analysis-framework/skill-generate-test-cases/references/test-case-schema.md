# 测试用例 JSON 契约

XMind 生成器和覆盖率分析器共用同一份用例数据。顶层可以是数组，也可以是包含 `test_cases` 数组的对象。

每条用例必须包含：

- `用例ID`：唯一 ID
- `用例标题`
- `测试点ID`
- `需求ID`
- `设计方法`：字符串或数组
- `步骤`：非空数组；每步必须有 `操作` 和 `预期`（也接受 `预期结果`）

可选字段包括 `模块`、`优先级`、`前置条件`、`备注` 和 `标签`。模块最多 8 层。

```json
{
  "test_cases": [
    {
      "用例ID": "TC-001",
      "模块": ["订单", "列表"],
      "用例标题": "按状态筛选订单",
      "优先级": "P1",
      "测试点ID": "TP-001",
      "需求ID": "REQ-001",
      "设计方法": ["EP", "DT"],
      "步骤": [
        {"操作": "打开订单列表", "预期": "显示订单列表"}
      ]
    }
  ]
}
```

生成器会把用例 ID、测试点 ID、需求 ID 和设计方法写入 XMind 节点。字段缺失、步骤为空、用例 ID 重复时，命令失败并说明原因。
